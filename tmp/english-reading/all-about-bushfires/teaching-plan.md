# 教学设计确认稿（Gate 1）

## 课程目标与讲解深度

- 学习者：六年级（预初，南模初中 Starter 阅读练习）
- 核心目标：读懂科普说明文 All About Bushfires；掌握卷面 Notes 的 13 个词汇/短语；理解定语从句、被动语态、make it + adj. + to do 句型；完成 3 道判断题 + 3 道简答题并学会回原文找证据。
- 讲解深度：初中入门级——重点讲句子结构、时态语态、固定搭配和影响理解的生词；不做逐词扫盲。
- 预计结构：片头 → 文章逐句精读（5 段 13 句）→ 判断题 Q01–Q03 → 简答题 Q04–Q06 → 答案总结卡 → 结束。
- 预计时长：约 14–17 分钟（参考：Lesson 1 共 11 句 13.9 分钟、Lesson 2 共 18 分钟）。
- deliveryMode：`questions-after-reading`（判断/简答为独立板块，全部放在文章精读之后）。

## 整体讲解流程

1. 开场：标题卡 "All About Bushfires" → 任务说明（精读 + 完成判断与简答）→ 文章结构总览：
   - P01 山火是什么、分布在哪里
   - P02 自然成因 + 自然循环
   - P03 山火对自然的三个好处
   - P04 人为成因（篝火未熄）
   - P05 气候变化让山火更大更难扑灭
2. 文章讲解：P01–P05 每句按「慢读英文 → 语法/搭配/生词 → 整句中文翻译」三步走。
3. 题目讲解：先判断题（第 1–3 题），再简答题（第 4–6 题）；每题按「题目态 → 答案态 → 证据态」推进。
4. 总结与结尾：总结卡逐行复盘六题答案，结束语。

## 文章讲解重点

| 句子 | 讲解重点 | 展示方式 |
|---|---|---|
| P01-S01 Bushfires are fires that burn in the bush. | that 引导的定语从句修饰 fires（下定义句型）；生词 burn；短语 in the bush | 慢读 + 从句框注 + 翻译 |
| P01-S02 These fires are common in hot and dry places, like Australia... | be common in 在…很常见；like = such as 举例 | 慢读 + 搭配讲解 + 翻译 |
| P02-S01 Bushfires can start naturally, such as when lightning strikes dry plants. | start naturally 自然发生；such as 举例；when 时间状语从句 | 慢读 + 搭配讲解 + 翻译 |
| P02-S02 Believe it or not, bushfires are part of a natural cycle. | 口语固定块 Believe it or not 信不信由你；part of a natural cycle | 慢读 + 短语讲解 + 翻译 |
| P03-S01 When a bushfire starts, it burns grass and kills insects that are bad for trees. | when 从句前置；that 定语从句修饰 insects；be bad for 对…有害；生词 kill | 慢读 + 双从句框注 + 翻译 |
| P03-S02 It makes more space for new plants to grow. | make more space for… 为…腾出更多空间；space [U] 用法提示 | 慢读 + 搭配讲解 + 翻译 |
| P03-S03 It makes more space for sunlight to get to the ground too. | 同上句型迁移；too 句末"也" | 慢读 + 搭配迁移 + 翻译 |
| P03-S04 This is good for animals because they can find new food and make new homes. | because 原因从句；be good for 与 be bad for 对比；find/make 并列动词 | 慢读 + 对比讲解 + 翻译 |
| P04-S01 Sadly, bushfires can be started by people. | 一般现在时被动语态 can be started by…（本课语法重点）；Sadly 评注副词 | 慢读 + 语态转换演示 + 翻译 |
| P04-S02 For example, a bushfire can start when someone hasn't correctly put out a campfire. | For example 举例；put out 扑灭（固定短语）；现在完成时否定 hasn't put out | 慢读 + 短语讲解 + 翻译 |
| P05-S01 Climate change doesn't start bushfires, but it makes them larger. | doesn't…but… 否定+转折；make + 宾语 + 比较级 larger；climate change | 慢读 + 转折结构讲解 + 翻译 |
| P05-S02 That's because hotter summers and stronger winds make it easy for fires to get started and to spread. | That's because…；hotter/stronger 比较级并列；make it + adj. + for sb/sth + to do（本课句型重点）；生词 spread | 慢读 + 句型框注 + 翻译 |
| P05-S03 This makes it harder for firefighters to put out these fires. | 上句句型迁移 easy→harder；合成词 firefighter | 慢读 + 句型迁移 + 翻译 |

词汇讲解随句进行（卷面 Notes 13 条全部覆盖：burn、in the bush、part、naturally、believe it or not、natural cycle、kill、space、sadly、for example、put out、climate change、spread）。

## 题目讲解与展示方式

| 题目 | 解题思路 | 展示模式 | 答案揭示 | 原文证据 |
|---|---|---|---|---|
| Q01 判断：Bushfires are common in Australia because it is hot and dry. | 定位词 Australia → P01：澳大利亚是炎热干燥地区之一，说法与原文一致 | option-cards（A. True / B. False 两张卡） | 答案态仅高亮 A 卡 | P01 全段，高亮 "These fires are common in hot and dry places, like Australia, Africa and parts of the US." |
| Q02 判断：Bushfires are always bad for trees and animals because they burn everything. | 抓绝对词 always / everything → 与 P03"烧掉害虫、腾出空间、对动物有益"矛盾 | option-cards | 答案态仅高亮 B 卡 | P03 全段，双高亮 "It makes more space for new plants to grow." + "This is good for animals because they can find new food and make new homes." |
| Q03 判断：Bushfires can be started by people and climate change. | 拆成两半：people ✅（P04）；climate change ❌（P05 明确"不引发、只放大"）→ 并列判断题一错即错 | option-cards | 答案态仅高亮 B 卡 | P05 全段，高亮 "Climate change doesn't start bushfires, but it makes them larger." |
| Q04 简答：List one natural way that bushfires can start. | 定位 naturally → P02 首句；答案取"闪电击中干燥植物" | short-answer（题目态：题干+思考区；答案态：参考答案句） | 答案态展示参考答案 "Bushfires can start when lightning strikes dry plants." | P02 全段，高亮 "Bushfires can start naturally, such as when lightning strikes dry plants." |
| Q05 简答：What makes it easy for bushfires to get started and to spread? | 题干几乎复述 P05 原句，定位 get started and to spread → 更热的夏天 + 更强的风 | short-answer | 答案态展示 "Hotter summers and stronger winds make it easy for fires to get started and to spread." | P05 全段，高亮 "hotter summers and stronger winds make it easy for fires to get started and to spread" |
| Q06 简答：Why are bushfires part of a natural cycle? | 归纳题：把 P03 的因果链串成答案（烧害虫 → 腾空间和阳光 → 新植物生长 → 动物受益） | short-answer | 答案态展示参考答案（英文因果句） | P03 全段，双高亮 "it burns grass and kills insects that are bad for trees. It makes more space for new plants to grow." + "This is good for animals because they can find new food and make new homes." |

## 需要用户确认的事项

1. **判断题选项建模**：卷面仅印"判断正误"未印选项；按判断题惯例建模为 A. True / B. False 两张选项卡（选项卡布局需要显式选项）。是否同意？
2. **简答题新增 short-answer 通用呈现模式**：题目态显示题干 + "组织你的答案"思考区（不显示答案）；答案态显示英文参考答案句 + 中文讲解；证据态回到原文段落高亮。渲染器当前无此模式，将在 Gate 2 批准后新增通用场景（不写死课文文本）。是否同意？
3. **Q02 / Q06 双证据高亮**：两题依据由相邻两句共同支撑，计划在证据段落中同时高亮两处。是否同意？
4. **配音声音**：skill 默认 Doubao dayi，但 Volcengine 自 2026-08-27 起报无权限（前两课已改用 edge-tts：Lesson 1 晓晓女声 / Lesson 2 云扬男声）。本课默认先用晓晓（Xiaoxiao，语速 -12%/-16% 对应 0.88/0.84）；TTS 前会再探测 dayi 是否恢复。是否同意？
5. 无其他未决项（"Did you know?" 板块卷面为空，不进入教学内容）。
